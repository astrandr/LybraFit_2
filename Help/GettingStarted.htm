About LybraFit

           

LybraFit is a simple and easy to use tool for Linear and Non-Linear Least Square Regression Analysis. Even though the tool implements basic functionality it is still efficient for quick analysis and reporting.

With LybraFit you can:

·         Manually enter, import or copy paste experimental data, tabulate a function or find inverse solution of a function. Importing data from a text file allows you to manage header lines, rearrange columns, and customize data columns.

·         Quickly perform regression analysis with tens of library functions or your custom defined function models, adjust parameters of the model and optimize regression with automatic non-linear fit.

·         Transfer data from and to other applications like MS Excel, MS Word and etc. via clipboard, while being able to handle different formats of the data.

·         Produce text and graphical report with satisfying resolution quality, easy and quickly annotate your report with data title and regression results.

·         Export data

·         Keep log of analysis results for different data and models.
