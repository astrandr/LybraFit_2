Customizing graph

           

To change the look of the plot select Settings > Graph from the menu or click on Graph settings button.

Graph setting dialogs opens.

The Axis tab allows you to modify the ticks range, step, font and color, as well as labels on both axis.

 

The Data tab allows you to modify the data markers type and color, fit line thickness and color.

In the Title  section you can provide text of the title (by default it is initialized to the title of the project), optionally include the current model name and approximation goodness (Standard Error).

 

 

On the Graph Area tab you can change the colors of the graph, axis and grid settings.
