Entering data

 

·        Start new data

·        Auto increment argument

·        Tabulate function with auto-calculated data value

·        Auto-calculate standard error

           

To enter new data select Data > New from the menu or click on the New Data button:

 

 

New data dialog will open

 

Enter a title and names for data columns and click Ok

This will open a new empty data table:

 

To have the first column values auto-incremented check the Auto Increment check box and enter the start, end value and steps:

 

 

Optionally you can set data to be auto-calculated by checking Calculated check box and entering a math formula as shown below:

                        When entering math expression use PI for π constant. For accepted math functions see the Math functions in the Appendix.

Checking the Error data check box will create third column where the error or uncertainty for each Y value in the second column can be entered manually.

If Calculated Std is checked the error will be automatically calculated every time this value is set or changed as square root of the value.
